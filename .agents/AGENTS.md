# Project Rules & Behavioral Constraints

## UI Modification Rules
1. **No Unsanctioned UI Edits**: NEVER modify any UI layout, components, or styling without explicit user permission.
2. **Document UI Changes (`adjust_ui.md`)**: Whenever UI edits are explicitly requested or approved, specify all exact locations modified and generate/update an `adjust_ui.md` file detailing what was changed and the precise rationale behind the modification.
